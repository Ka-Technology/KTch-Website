# Ka Technology website

The site for [ka-tch.com](https://ka-tch.com), built with Astro in `site/`.

- **Run locally:** `cd site && npm install && npm run dev`
- **Publish:** push to `main`. GitHub Actions (`.github/workflows/deploy.yml`) builds `site/` and deploys it to GitHub Pages.

The 2024 site (old `frontend/` and `backend/`) is in the git history and on the `gh-pages` branch.
