# Ka Technology website

The site for [ka-tch.com](https://ka-tch.com), built with Astro in `site/`.

- **Run locally:** `cd site && npm install && npm run dev`
- **Publish:** merge your changes into `main`, then run `./publish.sh`. It builds `site/` and pushes the result to the `gh-pages` branch, which GitHub Pages serves at ka-tch.com.

The 2024 site (old `frontend/` and `backend/`) is in the git history.
